## 📖 Overview

**Digital Image Processing with MATLAB** is a collection of practical MATLAB programs developed to explore and implement fundamental concepts of Digital Image Processing.

This repository demonstrates how digital images can be enhanced, transformed, filtered, segmented, compressed, and analyzed using mathematical operations and image processing algorithms.

It includes implementations of several important techniques, such as:

- Image enhancement and restoration
- Brightness and contrast adjustment
- Histogram processing and equalization
- Image thresholding and segmentation
- Edge detection
- Morphological operations
- Spatial and frequency-domain filtering
- Fourier transformations
- Image compression using PCA
- Feature detection and extraction
- Image resizing and geometric transformations
- Object detection and template matching

The repository serves as a practical learning resource for students, developers, and individuals interested in MATLAB programming, computer vision, and image analysis.

## 🎯 Project Objectives

The primary objectives of this repository are:

1. Understand the mathematical foundations of Digital Image Processing.
2. Implement image processing algorithms using MATLAB.

4. Understand image segmentation and thresholding methods.
5. Apply edge detection algorithms to identify image boundaries.
6. Study morphological operations for binary image processing.

8. Understand image compression and compression ratio calculations.
9. Implement feature detection and extraction techniques.
10. Develop practical programming skills for computer vision applications.

## 🚀 Installation and Setup

### Requirements

- MATLAB installed on your computer.
- MATLAB Image Processing Toolbox for programs that use its functions.
- Sample input images where required.

### Step 1: Clone the Repository

```bash
git clone https://github.com/shahidazam2020-oss/ImageProcessingWithMATLAB.git
```

### Step 2: Navigate to the Directory

```bash
cd ImageProcessingWithMATLAB
```

### Step 3: Open MATLAB

Launch MATLAB and open the cloned repository directory.

### Step 4: Select a MATLAB Program

For example:

```text
HarrisDetector.m
EdgeDetectionCanny.m
HistogramEqualization.m
FrequencyDomainFiltering.m
```

### Step 5: Execute the Program

Open the selected `.m` file in MATLAB and click **Run**.

Some programs require input images or specific MATLAB toolboxes. Ensure the required files and dependencies are available before execution.

---

## ▶️ Running the Programs

You can also execute a MATLAB script from the MATLAB Command Window:

```matlab
run('HarrisDetector.m');
```

For image-based programs, use the required input image in the working directory or update the image path inside the script.

Example:

```matlab
img = imread('sample_image.jpg');
imshow(img);
title('Input Image');
```
